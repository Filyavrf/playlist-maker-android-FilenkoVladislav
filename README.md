# playlist-maker-android-FilenkoVladislav
Учебный проект по созданию мобильного приложения

### Технические требования
Android Studio:Ladybug (2024.2.1) или новее.
JDK:17 или 21
Gradle:8.0+.
Min SDK:29 (Android 10.0).
Target SDK:34 (Android 14.0).
При поиске трека нажимать enter или на значок лупы.

В 3-ем спринте:
- Создан главный экран приложения 
- Реализована навигация между экранами через Intent
- Созданы заготовки для экранов Поиск и Настройки
- Настроен проект и базовая структура репозитория gitignore, README

В 4-ом спринте:
- Навигация: Реализован переход между главным экраном, поиском и настройками с использованием Jetpack Navigation Compose.
- Экран поиска: Создана вёрстка поисковой строки с иконками и логикой очистки запроса.
- Экран настроек: Реализованы системные интенты для отправки письма в поддержку, шеринга ссылки и перехода к юридическим документам.

В 5-ом спринте:
- Слой Data: Реализован сетевой клиент и репозиторий. Настроена конвертация данных из DTO в доменные сущности (`Track`).
- Слой Domain: Описаны интерфейсы для работы с данными, что позволяет UI-слою не зависеть от источника данных (принцип инверсии зависимостей).
- Эмуляция сервера: Создан класс `Storage` с тестовым набором данных и задержкой ответа для имитации реальной сети.
- Рефакторинг: Проведена полная переработка структуры пакетов по канонам Clean Architecture.

В 6-ом спринте:
- Слой UI: Реализован полнофункциональный экран поиска на Jetpack Compose.
- Архитектура MVVM: Внедрена `SearchViewModel`, которая отделяет бизнес-логику от отображения.
- Управление состоянием: Использованы `StateFlow` и `collectAsState` для реактивного обновления интерфейса без ручного вмешательства.
- Навигация: Экран интегрирован в общую структуру навигации приложения с поддержкой корректного возврата назад.

В 7-ом спринте:
- Реализован интерфейс экрана «Плейлисты».
- Внедрена кнопка FloatingActionButton (FAB) для создания новых плейлистов.
- Реализована всплывающая панель ModalBottomSheet, управляемая состоянием экран.
- Навигация: экран интегрирован в общую структуру через NavHost.

В 8-ом спринте:
- Реализована навигация между экранами "Поиск", "Плейлисты" и "Избранное".
- Добавлен экран поиска с отображением индикатора загрузки.
- Реализована имитация задержки сети при поиске треков.
- Настроен переход на экран деталей трека.
- Создан интерфейс добавления нового плейлиста.

В 9-ом спринте:
- Реализована реальная работа с сетью: приложение отправляет поисковые запросы к iTunes API через Retrofit.
- Добавлена обработка состояний экрана поиска:
    - Отображение индикатора загрузки (ProgressBar) во время выполнения запроса.
    - Плейсхолдер «Ничего не найдено» с изображением‑заглушкой при пустом результате поиска.
    - Плейсхолдер «Ошибка сервера» с изображением‑заглушкой и кнопкой «Обновить» при неудачном запросе (код ошибки).
- Кнопка «Обновить» повторяет последний неудавшийся поисковый запрос.
- Загрузка и отображение обложек треков через библиотеку Coil с плейсхолдером‑заглушкой на время загрузки.
- Каждый элемент списка результатов содержит обложку, название трека, имя исполнителя и длительность в формате mm:ss.
- Поле поиска оснащено кнопкой очистки, которая скрывает клавиатуру и очищает список результатов.
- Реализован переход на экран деталей трека с полной информацией о выбранном треке и возможностью добавить его в плейлист или в избранное.
- Все изменения выполнены без нарушения ранее реализованного функционала (плейлисты, избранное, настройки).

В 10-ом спринте:
- Реализовано постоянное хранение данных с использованием Room:
  - Плейлисты сохраняются в базе данных и отображаются после перезапуска приложения.
  - Треки, добавленные в «Избранное», сохраняются в БД, состояние сердечка восстанавливается при повторном открытии экрана трека.
- Реализована история поиска через DataStore:
  - История сохраняется в файле preferences, не стирается после закрытия приложения.
  - Ограничение на 10 последних запросов, без дубликатов, в обратном хронологическом порядке.
  - Добавлена кнопка «Очистить историю».
- Удалён мок-класс DatabaseMock, весь функционал переведён на реальную базу данных и DataStore.
- На экране «Избранное» корректно отображаются треки, помеченные сердечком, с возможностью удаления длительным нажатием.
- На экране деталей трека при повторном открытии сохраняется состояние избранного (сердечко заполнено, если трек уже в избранном).

В 12-ом спринте:
Экран Избранное:
- Отображение списка треков, добавленных в избранное.
- Реактивное обновление списка с использованием `StateFlow` и `Room`.
- Использование заглушек (`placeholder`) для треков без обложки.
- Реализовано удаление трека из избранного по долгому нажатию на элемент списка.
Добавление обложки плейлиста:
- Интеграция системного интента `ACTION_PICK` (`ActivityResultContracts.GetContent()`) для выбора изображения из галереи.
- Запрос runtime разрешений `READ_EXTERNAL_STORAGE` для Android 12 и ниже.
- Использование Android 13+ Photo Picker API без запроса разрешений.
- Сохранение URI изображения в базе данных Room (`PlaylistEntity`).
- Отображение выбранной обложки (или заглушки) в списках и деталях плейлиста с помощью библиотеки `Coil`.
